# Embedded PE ↔ guest GS ↔ Darwin

Run `python3 research/windows_native/loader/run_gs_pe_probe.py`. Two sequential
nice-15 compilations produce inert ASan/UBSan host tests and an **uninstrumented**
disposable GS child. The generated PE bytes/header and binaries exist only in
the recorded temporary `Products.noindex` directory. The runner retains hashes,
commands, PID/PGID, timeouts, stdout, negative results and exact cleanup evidence.

The fixture is an actual PE64 AMD64 EXE mapped by unchanged `pm_pe_load`, with
ordinary imports and relocation. Its TLS directory remains absent. Code is RX,
IAT R and data RW, independently queried with Mach before execution. Host checks
the entire mapped code against generated bytes, the relocated data pointer,
the one exact resolved IAT address, and both `CALL [RIP+disp32]` destinations.
Each call is immediately followed by a failure guard before another GS read.

`pm_gs_invoke_pe` installs guest GS in assembly, then calls the entry address
inside that mapping with the Win64 convention. The PE saves/restores nonvolatile
GPRs/XMM registers, reaches a small synthetic TLS vector via actual GS accesses,
writes data and markers, and calls the unchanged `pm_gs_import_gateway` through
its IAT. The gateway restores Darwin GS before the SysV callback and guest GS
before returning. The host callback checks pthread/errno and register sentinels,
then deliberately clobbers SysV-volatile XMM6–15/RDI/RSI. No host C is called
under guest GS. The wrapper checks/restores Darwin before returning to C.

Normal mode expects two TLS writes/two IAT callbacks, PE return 0 and the normal
marker. The second child deliberately returns callback failure 1: the PE must
take its immediate guard, perform only one TLS write/callback, return 1 and set
the error marker. This tests a normal refusal path, **not** a signal, failed GS
setter, or recovery from arbitrary guest faults. Callback-validation failures
have a separate counter and cannot be hidden by the expected refusal.

Both modes really unload, then query Mach to confirm no region covers the old
mapping. Host tests additionally reject a newly present TLS directory, unknown
DLL/symbol, a refusing resolver and unsupported ordinal requests without calling
the entry. No loader policy is relaxed and the earlier GS probe is unchanged.

Signal/private-protocol limits from [GS_PROBE.md](GS_PROBE.md) apply: single
thread, fatal default signals, other catchable signals masked for the interval,
child watchdog. UNSUPPORTED never means a passed transition. No static PE TLS
template allocation, `_tls_index` assignment, callback initialization, CRT,
SEH, signal recovery, reentrancy, real DLL/game or graphics is implemented.
There is no Wine, VM, Steam operation or installed-application change. Timing
is used solely for bounded execution, never as a performance measurement.

Primary specifications: [Microsoft PE format](https://learn.microsoft.com/en-us/windows/win32/debug/pe-format),
[x64 ABI](https://learn.microsoft.com/en-us/cpp/build/x64-calling-convention),
and the pinned Apple source links in GS_PROBE.md. No proprietary PE is embedded.
